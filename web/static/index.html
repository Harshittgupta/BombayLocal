    How it works

    1. Buy. Your phone makes a secret and sends only its one-way hash. The issuer adds it to the list of valid passes.
    2. Publish. The issuer posts one 32-byte fingerprint of the whole list (a Merkle root) on Ethereum, and the list itself on Arkiv.
    3. Prove. Your phone rebuilds the list from Arkiv, checks it against Ethereum, and makes a zero-knowledge proof: "my pass is in this list and valid today". The code changes every 10 minutes.
    4. Check offline. The checker's phone verifies the proof and the issuer's signature with no internet. Showing the same code twice turns Amber, then Red.

    Limits we state up front: duplicates are caught per scanner; the trusted setup is demo-grade; the authority is a single key (a multisig in production); payment is simulated. Details in the README.
